# RF2 - Gestión de Pacientes

## Descripción

Este módulo permite gestionar la información de los pacientes del Sistema de Gestión de Citas Odontológicas.

## Funcionalidades

- Registrar pacientes.
- Consultar información de pacientes.
- Actualizar datos de pacientes.
- Gestionar el estado de los pacientes.
